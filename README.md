# Stars Bot — заработок Telegram Stars за задания

Telegram-бот на **aiogram 3.x** для заработка Stars за выполнение заданий (CPA),
с реферальной системой, выводом Stars и встроенной админ-панелью.
Функционал и интерфейс повторяют логику бота `@stars_goobot` со скриншотов:
главное меню, задания с проверкой подписки, баланс, бонусы, профиль,
покупка трафика и полная админка.

## Возможности

**Пользователь**
- 🔒 Обязательная подписка на спонсоров перед использованием бота: экран
  с кнопками «📢 Подписаться» и «✅ Проверить»; пока подписки нет — бот
  не пускает в меню (настраивается в `SPONSOR_CHANNELS` / админке).
- 🚀 Главное меню: задания, баланс, приглашение друзей, бонус, профиль,
  покупка трафика.
- 📋 Задания: список с пагинацией, карточка задания, кнопка «✅ Проверить».
- 🔔 Проверка подписки на канал через `getChatMember` Telegram Bot API.
- ⭐ Начисление Stars на внутренний баланс только после проверки;
  защита от накрутки — задание засчитывается пользователю ровно один раз.
- 💰 Баланс: доступно / в заявках / выплачено, история начислений.
- 💸 Вывод Stars через заявку (минимум 50 ⭐, настраивается), статус `pending`;
  заявка автоматически публикуется в канале выплат `WITHDRAW_CHANNEL`
  с кнопками «✅ Подтвердить» / «❌ Отклонить» для администратора.
- 👥 Рефералка: `t.me/YourBot?start=ref_<id>`, бонус рефереру после
  N заданий друга + процент от его наград.
- 🎁 Бонусные задания и 🎟 промокоды.
- 👤 Профиль: язык, уведомления, партнёрский канал.
- 🛒 Покупка трафика: задания, рассылка, просмотры, показы — оплата
  Telegram Stars (XTR), «Мои заказы».

**Администратор** (ID из `ADMIN_IDS`, команда `/admin`)
- 📝 Редактирование текстов (приветствие, «Задания», «Баланс»,
  реф-переход, «Бонус», «Профиль», «Трафик», запрос вывода); сброс к дефолту.
- 📋 CRUD заданий: название, ссылка, тип (канал / бот / ссылка), награда,
  `chat_id`, бонусное, включение/выключение, удаление.
- 💸 Заявки на вывод: подтвердить (выплачено) / отклонить (Stars возвращаются) —
  как в личном кабинете `/admin`, так и кнопками прямо в канале выплат.
- 👥 Пользователи: список, карточка, поиск по ID/@username, блокировка,
  начисление Stars.
- 📢 Рассылка: текст/фото/видео, подтверждение, задержка между сообщениями,
  обработка `RetryAfter` и заблокировавших бота.
- ⚙️ Настройки: реферальный бонус, порог заданий, процент, минимальный вывод,
  цены на трафик.
- 🛒 Заказы трафика: список, отметить выполненным / отменённым.
- 👑 Автоназначение админа при первом запуске: если `ADMIN_IDS` пуст,
  администратором становится владелец канала `WITHDRAW_CHANNEL`
  (запасной вариант — первый пользователь с `/start`,
  флаг `BOOTSTRAP_FIRST_ADMIN`).

## Требования

- Python **3.10+** (проверено на 3.10.10);
- пакеты из `requirements.txt`: `aiogram==3.31.0`, `aiosqlite`,
  `python-dotenv`;
- SQLite (встроен в Python, отдельный сервер не нужен).

### Локальный запуск на этой машине

Рабочая конфигурация уже лежит в `.env` (файл в `.gitignore`):

- бот — `@emberstarsrobot`;
- канал заявок на вывод — `@EmberStarsPayment` (бот там администратор);
- спонсор обязательной подписки — `@eezfo` (бот там администратор);
- `ADMIN_IDS` — владелец канала и второй администратор; они проходят
  проверку подписки всегда (админ-байпас).

Запуск в отдельном окне:

```powershell
.\run_bot.bat
# или
.\\.venv\\Scripts\\python.exe main.py
```

Проверка токена, канала, спонсоров и списка администраторов:

```powershell
.\\.venv\\Scripts\\python.exe tools\\check_bot.py
```

После запуска напишите боту `/start`, затем `/admin` — откроется админ-панель.
Новые пользователи сначала увидят экран подписки на `@eezfo` с кнопками
«📢 Подписаться» и «✅ Проверить». Управление списком спонсоров —
`/admin` → «Настройки» → «Спонсоры (обязательная подписка)»; значение `—`
отключает проверку. Бот работает, пока запущен процесс; после правок кода
перезапустите его.

### Переменные окружения (`.env`)

| Переменная | Обязательно | Описание |
|---|---|---|
| `BOT_TOKEN` | да | токен от [@BotFather](https://t.me/BotFather) |
| `ADMIN_IDS` | рекоменд. | Telegram ID администраторов через запятую, без них админка недоступна |
| `DB_PATH` | нет | путь к SQLite (по умолчанию `data/stars_bot.sqlite3`) |
| `BOT_USERNAME` | нет | юзернейм бота без `@`; если пуст — определяется через `get_me` |
| `SUPPORT_CONTACT` | нет | контакт поддержки (используется в конфиге) |
| `WITHDRAW_CHANNEL` | нет | канал для заявок на вывод (`@username` или `-100...`); бот должен быть его администратором |
| `SPONSOR_CHANNELS` | нет | каналы обязательной подписки через запятую (`@eezfo` / ссылки); бот должен быть администратором этих каналов |
| `BOOTSTRAP_FIRST_ADMIN` | нет | `1` — если `ADMIN_IDS` пуст, назначить админом владельца канала выплат (запасной вариант: первый `/start`) |

После запуска:
1. Откройте бота и нажмите `/start`.
2. Админ: `/admin` → «Задания» → «Добавить задание» (для задания-подписки
   укажите `chat_id` канала, например `-1001234567890`, и добавьте бота
   администратором канала).
3. При желании измените цены и реферальные условия в `/admin` → «Настройки».

## Как устроена экономика

Все суммы хранятся целыми числами во внутренних единицах:
**1 ⭐ = 10 000 единиц** (`bot/utils.py: STARS_SCALE`). Это позволяет держать
дробные награды и цены из скриншотов (`0.5 ⭐`, `0.0345 ⭐`) без ошибок
округления. Ввод и вывод — в Stars, форматирование — `format_units()`.

Значения по умолчанию (`bot/defaults.py`):

| Параметр | По умолчанию |
|---|---|
| Награда за задание | задаётся админом |
| Бонус рефереру за активного друга | 5 ⭐ |
| Заданий друга для бонуса | 6 |
| Процент рефереру | 10% |
| Минимальный вывод | 50 ⭐ |
| Цена задания | 0.64 ⭐ |
| Цена рассылки за получателя | 0.025 ⭐ |
| Цена просмотра | 0.0345 ⭐ |
| Цена показа | 0.086 ⭐ |

Цены и условия меняются в админке без перезапуска бота.

## Проверка заданий и ограничения Telegram

- **Подписка на канал** — реальная проверка `getChatMember`; бот должен быть
  администратором канала, а в задании должен быть указан `chat_id` или
  `https://t.me/username` (ссылка нормализуется в `@username`).
- **Переход в бота** — если в задании указан `chat_id`, проверяется членство;
  если не указан — переход считается выполненным (Bot API не позволяет
  проверить запуск стороннего бота).
- **Внешняя ссылка** — проверить нельзя, начисление происходит по кнопке.
- **Вывод Stars** — Bot API не умеет переводить Stars пользователю. Заявка
  создаётся в БД, администратор выплачивает Stars вручную и подтверждает
  заявку в админке. При отклонении Stars автоматически возвращаются на баланс.
  Заявка также публикуется в `WITHDRAW_CHANNEL` с кнопками
  «✅ Подтвердить» / «❌ Отклонить» — решение можно принять прямо в канале,
  сообщение обновится на «выплачена»/«отклонена».
- **Обязательная подписка на спонсоров** — проверяется через `getChatMember`
  при `/start` и при любом действии в боте. Пока пользователь не подписан,
  вместо меню показывается экран с кнопками «Подписаться» и «Проверить».
  Каналы задаются в `SPONSOR_CHANNELS` (применяется один раз при запуске)
  и далее редактируются в `/admin` → «Настройки» → «Спонсоры»
  (`—` отключает проверку). Администраторы из `ADMIN_IDS` проверку проходят
  всегда. Бот должен быть администратором спонсорских каналов, иначе
  Telegram не даёт проверить подписку.
- **Рассылка** — отправляется всем пользователям из БД; бот не может писать
  тем, кто его заблокировал (такие пользователи помечаются в БД).

### Таблицы БД

`users`, `tasks`, `task_completions` (уникальность user+task — защита от
накрутки), `withdrawals`, `referrals`, `settings`, `transactions`, `orders`,
`promo_codes`, `promo_redemptions`.

Схема создаётся автоматически при первом запуске, дефолтные настройки
засеиваются в таблицу `settings`.

Интеграционные тесты прогоняют настоящий `Dispatcher` + `ContextMiddleware`
с фейковой сессией Bot API (без токена и сети): `/start`, все разделы меню,
проверку задания с `getChatMember`, FSM вывода, промокод, покупку трафика,
`pre_checkout_query`/`successful_payment`, админку и рассылку.

## Полезно знать

- Файл `.env` содержит секретный токен — не коммитьте его (он в `.gitignore`).
- Для работы проверки подписок бот должен быть администратором каналов.
- `data/*.sqlite3` и WAL-файлы также исключены из git.
- Кнопка «Админ-панель» видна только ID из `ADMIN_IDS`; команда `/admin`
  для остальных отвечает отказом.
- Если нужно ограничить показ заданий — выключите задание в админке
  (кнопка «🔴 Выключить»), оно останется в БД.
- Кнопки выбора языка сохраняют выбор в профиле, но тексты интерфейса пока
  русские (локализация — отдельная задача).
- Промокоды хранятся в таблице `promo_codes` и создаются через
  `Database.create_promo(code, amount_units, uses)`; отдельного раздела
  админки для них в ТЗ не было.
- Заявка на вывод списывает Stars с баланса сразу (они «в заявках»);
  при подтверждении админом выплата происходит вручную, при отклонении
  Stars возвращаются автоматически.
